# apps/web

TanStack Start (React, file-based routing) + Tailwind v4.

- Pages live in `src/routes`. `src/routeTree.gen.ts` is generated by the dev server or
  build; do not edit it.
- Load data in a route `loader`, using functions from `@qlastakit/api-client`.
- Use components from `@qlastakit/ui`. Add new shared components there, not here, if another app
  could use them.
- No business logic here. If you need it, add it to `services/api` and regenerate the
  client.
- API base URL comes from `VITE_API_URL` in the root `.env`.
