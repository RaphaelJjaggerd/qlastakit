# apps/web

TanStack Start (React, file-based routing) + Tailwind v4.

- Pages live in `src/routes`. `src/routeTree.gen.ts` is generated by the dev server or
  build; do not edit it.
- Fetch data with the query hooks generated into `@qlastakit/api-client`
  (`useQuery(listNotesOptions())`, `useMutation(createNoteMutation())`). Never hand-written
  `fetch`.
- Use components from `@qlastakit/ui`. Add new shared components there, not here, if another app
  could use them.
- No business logic here. If you need it, add it to `services/api` and regenerate the
  client.
- The browser calls `/api` on its own origin; the dev server proxies it to the API. Server-side
  code uses `API_INTERNAL_URL` from the root `.env`.
- The web app imports no core, db or service code (lint enforces it).
