# apps/web

TanStack Start (React, file-based routing) + Tailwind v4.

## Prime directives

1. **Be additive.** Add a file or a line to a config. Do not rewrite the shell, the config or
   a shared component to fit one page.
2. **Reuse the building blocks.** Components come from `@qlastakit/ui` (list in
   `packages/ts/ui/component-inventory.md`). Add a new shared component there, not here, if
   another app could use it.
3. **Never hardcode colours, shadows or durations.** Token utilities only (`bg-card`,
   `text-muted-foreground`, `shadow-raised`). The rules are in `packages/ts/ui/DESIGN.md`;
   `pnpm lint` and verify enforce the ones that can be checked.
4. **Keep it typed.** No `any`. Message keys, route paths and the generated client are typed;
   let the compiler catch a wrong one.

## Rules

- Pages live in `src/routes`, one file per route. `src/routeTree.gen.ts` is generated by the
  dev server or build; do not edit it.
- Fetch data with the query hooks generated into `@qlastakit/api-client`
  (`useQuery(listNotesOptions())`, `useMutation(createNoteMutation())`). Never hand-written
  `fetch`.
- Visible text is a message key, never a string: add it to `src/messages/en.json` and read it
  with `useTranslation()`.
- Access is declared on the route (`protect(key, authority)` from `@/access`), not checked
  inside the page. Use `hasAuthority` only for conditional UI.
- No business logic here. If you need it, add it to `packages/ts/core` and the API route, then
  run `mise run contract`.
- The browser calls `/api` on its own origin; the dev server proxies it to the API. Server-side
  code uses `API_INTERNAL_URL` from the root `.env`.
- The web app imports no core, db or service code (lint enforces it).

## Recipe: add a page (two steps)

Example: a page at `/reports`. `src/routes/index.tsx` is the model.

1. **Route file** `src/routes/reports.tsx`: export `Route` with
   `createFileRoute("/reports")({ ...protect("reports"), component: Reports })`. `protect`
   sets the static data (`key`) and the before-load access check; pass roles as the second
   argument to restrict it. For a public page, give `staticData: { key: "reports" }` instead.
   A route can override the layout with `layout` in its static data (`stacked-side`,
   `auth-side`, `blank`). The component uses `useTranslation()` for text and `@qlastakit/ui`
   for building blocks. Run `pnpm --filter @qlastakit/web dev` once (or `build`) so
   `routeTree.gen.ts` picks the route up. That file is tracked in git: commit the regenerated
   version with the route.
2. **Navigation and text** (skip the nav node if the page is not in the menu): add the
   message keys to `src/messages/en.json` (`"nav.reports"`, plus the page's own), then add a
   node to `navigationConfig` in `src/config/navigation.config.ts` whose `key` equals the
   route's static data key (`"reports"`), with `path: "/reports"`, `titleKey: "nav.reports"`,
   an `icon` from `src/shell/nav-icons.tsx`, `type: "item"` (a plain page; `"collapse"` and
   `"title"` are for groups), `authority` (`[]` means any signed-in user) and `subMenu: []`.
   All of `key`, `path`, `titleKey`, `icon`, `type`, `authority` and `subMenu` are required.

Then run `scripts/verify.sh`.
